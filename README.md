# 🎃 Halloween Dashboard 👻

## 📊 Project Overview

The **Halloween Dashboard** is an interactive data visualization project designed to analyze Halloween activities and visitor trends across different years.

The dashboard provides insights into **year-by-year variations, visitor strength, Halloween activity trends, total activity count, and future event forecasts**.

The project combines data analysis with a creative Halloween-themed design to make the dashboard informative, visually appealing, and easy to understand.

## ✨ Dashboard Features

- 🎃 **Total Count** – Displays the overall activity count of **13,980**
- 📅 **Year-by-Year Variation** – Compares Halloween activity across different years
- 👥 **Visitor Strength** – Shows visitor activity based on the day of the week
- 📈 **Halloween Activity Trend** – Visualizes changes in Halloween activities from 2008–2014
- 🔮 **Future Event Forecast** – Provides a visual representation of future activity trends
- 👻 **Halloween Theme** – Uses Halloween images and colors to create an engaging dashboard

---

## 📊 Key Insights

The dashboard helps identify:

- Changes in Halloween activity over the years
- Years with higher and lower activity
- Days with stronger visitor participation
- Overall Halloween activity patterns
- Possible future trends based on historical data

## 🎯 Project Objective

The objective of this project is to transform Halloween-related data into meaningful visual insights. The dashboard makes it easier to understand historical patterns, visitor behavior, and future trends using charts and visual elements.
